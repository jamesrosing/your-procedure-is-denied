# Review: your-procedure-is-denied (build/)

**Verdict.** The core referential idea is sound and unusually well documented: verbatim-quote checking, fail-closed verdicts, and the stored-result tables are real and mostly reproduce exactly. But the gate is not the fabrication-proof check the Abstract and Conclusion claim. I confirmed multiple inputs in the gate's own declared scope — dates, numbers, codes, and anatomical sides — that return `verified`, including one assembled packet that returns `pass`. The mutation study's "5,824 of 5,824 hard corruptions caught" is true only inside the corruption shapes the harness knows how to generate; the bypasses below are outside those shapes and outside [the gate tests](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/build/tests/litmus.test.ts>). Environment note: `cd build && npm test` could not run in this checkout — `node_modules` is absent (`ERR_MODULE_NOT_FOUND: tsx`) and the sandbox has no network. All gate findings below were instead confirmed by executing the real [litmus.ts](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/build/src/litmus.ts>) module (copied to `/tmp`, imports rewired from `.js` to `.ts` only) under Node type-stripping, against the fixture chart from the gate's own tests. The repo was not modified (`git status` clean).

## Blocker

**B1. Dates written with a month name are not checked at all.** [sentenceHardTokens in litmus.ts:188](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/build/src/litmus.ts:188>) recognizes only ISO and slash dates; month names produce no token. Ran: citing `note-002` (dated 2025-08-14, quote the PT quote), both `The therapy note of September 14, 2025 documents completion.` and the December variant return `verified`. The existing test at [litmus.test.ts:197](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/build/tests/litmus.test.ts:197>) only exercises a wrong *day*, so this is untested. A model (or a judge in the viewer's gate editor) can move any appointment, surgery, or service date by months.

**B2. The number words "one", "zero", ordinals, and "dozen" are invisible to the gate.** [NUMBER_WORDS in litmus.ts:127](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/build/src/litmus.ts:127>) omits `one`/`zero`; ordinal forms (`fifteenth`) fail the `\b(...)\b` word boundary; `dozen` is unlisted. Ran, all `verified` against the test fixture: `The patient completed one week of physical therapy.` (entry: 12 weeks), `...zero weeks...`, `She was on one antianginal agent.` and `She was on a dozen antianginal agents.` (entry lists three drugs with no count — the exact "count the chart never states" case the README says is blocked, bypassed by wording), `She had XXIV months of upper back pain.` (Roman numerals also untokenized). The mutation harness mirrors the same word list ([mutate.ts:75](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/build/scripts/mutate.ts:75>)), so the spike-in cannot see this class either.

**B3. Anatomical side can be smuggled past the idiom mask or as an abbreviation.** [SIDE_IDIOM in litmus.ts:182](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/build/src/litmus.ts:182>) masks `right at`, `left in`, `right to`, etc. wherever they occur, and [the side extractor at litmus.ts:192](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/build/src/litmus.ts:192>) only matches the bare words `left|right`. Ran, all `verified` citing an entry with no side at all: `The lesion on the right at the chest wall persisted…`, `The RT knee pain persisted…`, `The R knee pain persisted…` — while the control `Her right shoulder pain…` correctly returned `needs-citation`. Laterality is the highest-harm token class in this domain (wrong-side surgery), and v1.4/v1.5 closed earlier side leaks while leaving this one.

**B4. The alphabetic part of a drug/procedure code is never compared.** [The code pattern at litmus.ts:191](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/build/src/litmus.ts:191>) (`\b[a-z]\d{2}…\b`) cannot match a 4-digit code like `J9271`, so only the digits are checked. Ran: against an entry reading `Start J9271 infusion today`, the sentences `She started K9271 infusion.` and `She started Q9271 infusion.` both return `verified`. J→K changes the drug entirely; the gate sees only `9271`.

## Serious

**S1. A sentence's content is never checked against its own quote, and evidence relevance is never checked — assembled, these pass a full packet.** [checkSentence in litmus.ts:298](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/build/src/litmus.ts:298>) checks only that the quote exists in the entry and that hard tokens exist *somewhere* admissible; the evidence loop ([litmus.ts:328](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/build/src/litmus.ts:328>)) verifies a quote's presence, not its bearing on the criterion, and [litmus.ts:343](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/build/src/litmus.ts:343>) marks a criterion verified on any verbatim quote. Ran: one packet combining B1+B2+B4+B3 fabrications plus `Blood pressure check` cited as evidence for the resection-weight criterion returned `verdict: pass`, all sentences `verified`. Separately, `She has metastatic breast cancer requiring urgent mastectomy and chemotherapy.` citing the quote `Still in the supportive bra` returned `verified` (fabricated diagnosis, no hard token). The README's Limitations ([README.md:426](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/README.md:426>)) discloses the sentence-vs-quote gap honestly, but the Abstract's "every sentence held to the record" and the Conclusion's "has not let a fabrication through in 5,824 tries" ([README.md:442](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/README.md:442>)) overstate what was measured.

**S2. Token provenance is pooled, so numbers can be recombined into fabricated quantities.** [sourceTokens in litmus.ts:201](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/build/src/litmus.ts:201>) splits every date into year/month/day components admitted as bare numbers. Ran, all `verified`: `She completed 14 weeks of physical therapy.` citing the entry dated 08-14 that says 12 weeks (14 comes from the date); `She completed 6 months of physical therapy…` (6 comes only from the criterion text); `The estimated resection was 2,200 grams…` (composed from `5 foot 2, 200 pounds` in the cited entry); `…690 grams on the right and 724 on the left…` (the entry assigns them the other way round — pairing is never checked). The collision class in Table 3 covers criteria/denial/facts reuse, but date components, thousands composition, and side↔number re-pairing are not among the 9,518 mutations.

**S3. Non-ASCII digits bypass number checking entirely.** JS `\d` is ASCII-only and [canon in litmus.ts:115](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/build/src/litmus.ts:115>) performs no digit folding. Ran: `The estimated resection was ９９９ grams.` (fullwidth digits) returns `verified` against an entry whose only weights are 724/690. Lower likelihood from a model than B1–B4, but it is a one-character-class fix (normalize Unicode decimal digits in `canon`).

**S4. A mid-loop provider failure silently zeroes cost, latency, usage, and the tool trace.** [proposeAgentic in provider.ts:183](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/build/src/provider.ts:183>) accumulates usage/trace locally and returns them only on success; any throw (rate limit on turn 5 of 24, say) propagates to [runCase in harness.ts:360](</tmp/claude-1000/-home-james-projects-your-procedure-is-denied-build/9fc98b9d-e5c7-45fe-9c8e-9ef9e757f00f/scratchpad/muse-review-strong/build/src/harness.ts:360>), which records `EMPTY_USAGE`, `costUsd: 0`, `latencyMs: 0`.

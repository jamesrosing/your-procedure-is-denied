# /build

Everything in this directory was written during the Meta Global AI Developer Hackathon, October 26 to November 4, 2026. See [NEW-WORK.md](../NEW-WORK.md) for the ledger.

Contents:

- `src/test-call.ts`: one call to muse-spark-1.3 on the Meta Model API through the Anthropic SDK base-URL swap. Run with `npm run test-call`; it reads `MODEL_API_KEY` from the repository `.env`.
- `src/provider.ts`: the provider seam. `messagesProvider` for Meta and Baseten, `openAiProvider` for Fireworks. `src/schema.ts` is the appeal output contract and validator; `src/cost.ts` the price table.
- `src/smoke.ts`: one synthetic denial through each configured host. `npm run smoke`. Needs `MODEL_API_KEY` and optionally `BASETEN_API_KEY` in `.env`.
- `synthetic/`: the 50-case synthetic denial set across the high-dollar denial categories, generated by `src/synthetic/generate.ts` from the templates in `src/synthetic/templates/` (`npm run synthetic`). See `synthetic/README.md` for the composition, the stakes, and the labels.
- `tests/`: `npm test`. No network; the transport is stubbed.
- `src/probe.ts`: effort, JSON Schema, and prompt-cache probe on a synthetic chart. Run with `npm run probe`. Costs a few cents.

Models are called only over hosted APIs; nothing runs locally.

All data used here is synthetic. No real patient data is used anywhere in this repository.

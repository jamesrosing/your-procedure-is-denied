# /build

Everything in this directory was written during the Meta Global AI Developer Hackathon, October 26 to November 4, 2026. See [NEW-WORK.md](../NEW-WORK.md) for the ledger.

Contents:

- `src/provider.ts`: the provider seam. `messagesProvider` for the Meta Model API and Baseten through the Anthropic SDK base-URL swap, `openAiProvider` for OpenAI-compatible hosts. Sends effort, the JSON Schema output contract, and a cache marker; never sends the fields the Meta endpoint rejects. `src/schema.ts` is the appeal contract and validator (every sentence and every piece of evidence carries a verbatim quote from a cited chart entry); `src/cost.ts` the price table.
- `src/litmus.ts`: the LITMUS gate, written from the two Zenodo papers. Deterministic, fail-closed, external to the model. Per sentence: resolve the citation, require the quote verbatim in that entry, require every number, date, code, and laterality to be sourced from the entry, the criteria, the denial, or the case facts. Only this module can mint `verified`.
- `src/harness.ts`: runs the 50 cases through a provider and the gate, scores each against the grading key, and writes a results file. `npm run harness -- --provider meta --model muse-spark-1.3` (or `--provider baseten --model meta-models/muse-spark-open-1026`). Concurrency 8, effort low.
- `results/`: one results file per model from the October 27 runs. Each holds the run settings, the summary (outcomes, gate pass rate, sentences verified, latency percentiles, tokens, cost, stakes defended, citation precision), and every case with its draft and the gate's per-sentence record. The repository README reports the summaries.
- `synthetic/`: the 50-case synthetic denial set, generated by `src/synthetic/generate.ts` from the templates in `src/synthetic/templates/` (`npm run synthetic`). See `synthetic/README.md` for the composition, the stakes, and the labels.
- `viewer/`: the judge-facing replay page. `npm run viewer` copies `results/` and `synthetic/cases/` into `viewer/data/`, bundles `viewer/src/main.ts` to `viewer/app.js`, and typechecks; then serve the directory statically (`npm run viewer:serve`, port 8787). `viewer/src/replay.ts` holds the replay logic as pure functions (timeline, state at a cursor, scoreboard rows) and is tested; `main.ts` only renders.
- `tests/`: `npm test`. 80 tests, no network; the transport is stubbed.
- `src/smoke.ts`: one synthetic denial through each configured host (`npm run smoke`). `src/probe.ts`: effort, JSON Schema, and prompt-cache probe (`npm run probe`). `src/test-call.ts`: the first call to the Meta Model API (`npm run test-call`). Each reads keys from the repository `.env`: `MODEL_API_KEY`, and `BASETEN_API_KEY` for Baseten.

Models are called only over hosted APIs; nothing runs locally.

All data used here is synthetic. No real patient data is used anywhere in this repository.
